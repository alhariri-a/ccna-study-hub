# DHCP-LAN

Simple LAN topology built in Cisco Packet Tracer for practicing DHCP and switch-based networking.

---

# Network Overview

This topology includes:

* 1 Core Switch
* 2 Access Switches
* Multiple PCs
* 1 DHCP Server

All devices are connected inside a single LAN and receive IP addresses automatically from the DHCP server.

---

# Topology Structure

```text
                DHCP Server
                      |
                [Core Switch]
                 /          \
        [Access Switch]  [Access Switch]
           PCs...           PCs...
```

---

# Features

* Automatic IP assignment using DHCP
* PC-to-PC communication testing (Showing the pic daown)
* Multi-switch LAN topology
* Centralized DHCP server
* Structured switch design

---

# Technologies Used

* Cisco Packet Tracer
* DHCP
* Ethernet Switching
* IPv4 Addressing

---

# Purpose

This project was created for networking practice to understand:

* LAN communication
* DHCP configuration
* Switch connectivity
* Hierarchical LAN design
