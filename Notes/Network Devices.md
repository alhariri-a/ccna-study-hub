# Network Devices Notes

## What is a network device?
A network device is hardware used to connect devices together and allow communication between them.

### Router
- Connects different networks together
- Example: connects your home network to the internet

### Switch
- Connects devices inside the same network
- Example: connects PCs and printers in a LAN

### Hub
- Basic device that connects devices together
- Not smart like a switch


### Modem
- Connects your network to the ISP
- Used for internet access

### Firewall
- Protects the network
- Blocks unwanted traffic
- Used for security

### Server
- Provides services to other devices
- Examples:
  - Web server
  - File server
  - DNS server

### Client
- Device that uses services from a server
- Examples:
  - PC
  - Laptop
  - Phone
